All API errors are returned as `application/problem+json` per [RFC 9457](https://datatracker.ietf.org/doc/html/rfc9457). The shape:

```json
{
  "type": "https://rubric.dev/problems/invalid_identity",
  "title": "Invalid identity",
  "status": 401,
  "detail": "Token is missing, malformed, revoked, or expired.",
  "instance": "/v1/events"
}
```

Specific problem types may add typed extensions (e.g., `retryAfter` on rate limits).

## Catalog

| Type | HTTP | When |
| --- | --- | --- |
| `unauthenticated` | 401 | No `Authorization` header, or the header doesn't parse. |
| `invalid_identity` | 401 | JWT or enrollment token is missing, malformed, revoked, or expired. |
| `forbidden` | 403 | Action is not allowed for this credential's scope (e.g., enrolling a name whose identity is revoked). |
| `identity_agent_mismatch` | 403 | An audit event's `agentId` does not match the JWT's `sub`. |
| `not_found` | 404 | Resource doesn't exist (audit event, policy, agent). |
| `validation_failed` | 400 | Request body or query failed Zod validation. Has a `errors` array with per-field detail. |
| `enrollment_rate_limited` | 429 | Per-token enrollment rate-limit hit. Has `retryAfter` (seconds). |
| `enrollment_token_invalid` | 401 | Enrollment token is malformed, revoked, or expired. |
| `no_active_org` | 401 | Clerk session has no active organization. |
| `internal_error` | 500 | Bug in the control plane. Includes a request id for support. |

## Validation errors

`validation_failed` responses include the offending fields:

```json
{
  "type": "https://rubric.dev/problems/validation_failed",
  "title": "Validation failed",
  "status": 400,
  "detail": "Request body failed validation.",
  "errors": [
    {
      "code": "invalid_type",
      "expected": "string",
      "received": "undefined",
      "path": ["agentName"],
      "message": "Required"
    }
  ]
}
```

## Rate-limit responses

`enrollment_rate_limited` responses include both the standard `Retry-After` HTTP header and a typed `retryAfter` field in the body (seconds):

```json
{
  "type": "https://rubric.dev/problems/enrollment_rate_limited",
  "title": "Enrollment rate limit exceeded",
  "status": 429,
  "detail": "This token has hit its hourly enrollment cap.",
  "retryAfter": 1800
}
```

Wait the indicated time, then retry. The SDK does this automatically with exponential backoff.

## SDK exception mapping

The Python SDK turns problem responses into `GovernanceProblemError` exceptions. See [SDK errors](/sdk-python/errors).
