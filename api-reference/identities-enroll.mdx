---
title: "POST /v1/identities/enroll"
description: "Self-bootstrap a new agent identity using an enrollment token."
icon: "plug"
---

The SDK uses this endpoint on cold-start to create an identity and get its first JWT-SVID. Idempotent on `agentName` — restarts and redeploys return the same identity row with a fresh JWT.

## Request

```http
POST /v1/identities/enroll
Authorization: Bearer enr_<prefix>.<secret>
Content-Type: application/json

{
  "agentName": "payments-bot"
}
```

### Body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `agentName` | `string` | yes | 1–128 chars. Normalized to lowercase, dash-separated. |

## Response 200

```json
{
  "token": "eyJhbGciOiJFZERTQSI...",
  "expiresAt": "2026-05-10T16:09:29.123Z",
  "agentId": "payments-bot",
  "identityId": "9c2e5d4b-..."
}
```

| Field | Notes |
| --- | --- |
| `token` | The JWT-SVID. Use as `Authorization: Bearer <token>` for subsequent SDK-direction calls. |
| `expiresAt` | ISO timestamp. Refresh before this. |
| `agentId` | The bound id (also the JWT's `sub`). |
| `identityId` | Database row id. Stable across token refresh. |

## Errors

| Status | Type | When |
| --- | --- | --- |
| `401` | `invalid_identity` | Token missing, malformed, revoked, or expired. |
| `403` | `forbidden` | `agentName` resolves to an identity that is **revoked**. Operator must un-revoke or use a different name. |
| `429` | `enrollment_rate_limited` | Per-token rate limit exceeded. `retryAfter` (seconds) included. |

## cURL

```bash
curl -X POST $RUBRIC_API/v1/identities/enroll \
  -H "Authorization: Bearer $AG_ENROLLMENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"agentName":"payments-bot"}'
```

## Idempotency

Calling enroll multiple times for the same `(orgId, agentName)` always returns the same `identityId` and `agentId`. The `token` rotates on every call (fresh `iat`/`exp`). The SDK relies on this — every cold boot returns a fresh JWT bound to the same identity row.

The "revoked → 403" rule is the one exception. A revoked identity cannot be resurrected by re-enrolling. The operator must explicitly un-revoke (or a fresh agent name must be used).
