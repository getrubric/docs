---
title: "POST /v1/traces"
description: "Upload the conversation transcript for a session."
icon: "route"
---

Called by the SDK every time you pass a `TraceContext` to `evaluate()`. The endpoint upserts on `(sessionId, agentId)` — uploading a longer transcript replaces the previous one.

## Request

```http
POST /v1/traces
Authorization: Bearer <JWT-SVID>
Content-Type: application/json

{
  "sessionId": "sess-42",
  "agentId": "payments-bot",
  "messages": [
    {"role": "user", "content": "Delete the staging logs"},
    {"role": "assistant", "content": "I'll start by listing them."},
    {
      "role": "tool_use",
      "toolName": "list_files",
      "args": {"path": "/var/log"},
      "toolUseId": "call_1"
    }
  ]
}
```

### Body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `sessionId` | string | yes | Same id you pass to `evaluate()`. |
| `agentId` | string | yes | **Must equal the JWT's `sub`.** |
| `messages` | array | yes | Ordered list of messages. See types below. |

### Message types

| `role` | Other fields |
| --- | --- |
| `"user"` | `content: string` |
| `"assistant"` | `content: string` |
| `"tool_use"` | `toolName: string`, `args: object`, `toolUseId?: string` |
| `"tool_result"` | `content: string`, `isError: boolean`, `toolUseId?: string` |

## Response 201

```json
{
  "traceId": "9c2e5d4b-...",
  "tracePosition": 12,
  "messageCount": 13
}
```

| Field | Notes |
| --- | --- |
| `traceId` | UUID for the trace blob. Pin to the audit event. |
| `tracePosition` | The position (index) within `messages` of the *just-appended* tool call. The dashboard highlights this message when the audit row is clicked. |
| `messageCount` | Total messages stored. |

## Errors

| Status | Type | When |
| --- | --- | --- |
| `400` | `validation_failed` | Body is missing fields or malformed. |
| `401` | `invalid_identity` | JWT missing, malformed, revoked, or expired. |
| `403` | `identity_agent_mismatch` | `agentId !== sub`. |

## Storage

Traces are stored as JSON blobs keyed on `(orgId, sessionId, agentId)`. The latest version replaces the previous on each upload — older versions are not retained.

Retention defaults to 30 days. Configure with `TRACE_RETENTION_DAYS` env var on the control plane.

## cURL

```bash
curl -X POST $RUBRIC_API/v1/traces \
  -H "Authorization: Bearer $JWT" \
  -H "Content-Type: application/json" \
  -d '{"sessionId":"...","agentId":"...","messages":[...]}'
```

## Why upsert?

The SDK uploads the full running transcript on every `evaluate(trace=trace)` call. The blob grows over the conversation. Storing only the latest is the right tradeoff: the dashboard always renders the trace as it existed when the user clicked the audit row, and we don't pay for partial-transcript versions no one will ever look at.
